# Завдання №1 — Домен і модель даних (ER)

**Дисципліна:** Компоненти програмної інженерії.

**Тема проєкту:** Інформаційна система онлайн-магазину друкованих книг.

## Опис проєкту
Проєкт присвячено моделюванню предметної області онлайн-магазину друкованих книг. Система передбачає перегляд каталогу, пошук книг, отримання інформації про авторів, жанри та видання, а також оформлення замовлень. Один твір може мати декілька видань, що відрізняються видавництвом, роком публікації, ISBN, ціною та кількістю доступних примірників. Замовлення можуть оформлювати як зареєстровані покупці, так і гості без реєстрації.

## Мета завдання
Обрати домен і описати дані як модель сутностей і зв'язків (ER).

## Основні сутності
1. BOOK — книга.
2. AUTHOR — автор.
3. GENRE — жанр.
4. EDITION — видання.
5. PUBLISHER — видавництво.
6. USER — покупець.
7. ORDER — замовлення.
8. ORDER_ITEM — позиція замовлення.

## Основні бізнес-правила
- Одна книга може мати декілька видань.
- Кожне видання належить одній книзі та одному видавництву.
- Для початкової моделі книга має одного автора й один основний жанр.
- Замовлення можна оформити без реєстрації.
- Замовлення містить одну або декілька позицій.
- Кожна позиція замовлення пов'язана з конкретним виданням.
- Кількість замовлених примірників не повинна перевищувати доступні складські залишки.

## Перевірка ER-діаграми
Для відтворення ER-діаграми:
1. Відкрити файл `diagrams/er-model.mmd`.
2. Скопіювати його вміст.
3. Перейти до редактора https://mermaid.live/.
4. Вставити код у редактор.
5. Перевірити, що діаграма відображається без помилок.
Готове графічне представлення збережено у файлі
`diagrams/Діаграма.png`.
Запуск програмного застосунку не передбачений, оскільки результатом завдання є концептуальна ER-модель.
