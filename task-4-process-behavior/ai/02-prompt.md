## Оригінальний запит користувача

У завданні №4 нам пропонують три типи діаграм та п'ять варіантів їх реалізації. Допоможи мені порівняти ці варіанти та визначити, який із них краще підійде для мого проєкту Онлайн-магазин друкованих книг, а саме для UC-04 Оформлення замовлення. Врахуй складність реалізації, читабельність діаграм, можливість створення розгалужень, паралельних процесів, обміну повідомленнями між учасниками, зручність роботи з GitHub та відповідність вимогам викладача. Наведи переваги та недоліки кожного варіанта у вигляді таблиці та поясни, який варіант ти рекомендуєш і чому.

## Контекст звернення

У межах завдання 4 необхідно обрати спосіб моделювання процесу UC-04 Оформлення замовлення для проєкту Онлайн-магазин друкованих книг. Розглядаються п'ять варіантів:

- Activity — Mermaid flowchart;
- Activity — PlantUML activity;
- BPMN — bpmn.io;
- BPMN — Camunda Modeler;
- Машина станів — Mermaid stateDiagram-v2.

Основою для вибору є матеріали дисципліни МАВПЗ, ER-модель завдання 1, сценарії Gherkin та функціональні вимоги завдання 2, а також Sequence Diagram завдання 3.

## Результат звернення

ШІ порівняв п'ять варіантів за складністю реалізації, читабельністю, підтримкою розгалужень і паралельних процесів, можливістю відображення повідомлень між учасниками та інтеграцією з GitHub. Було визначено, що для UC-04 найбільш доречними є Activity та BPMN, оскільки вони відображають послідовність дій і альтернативні шляхи виконання процесу. PlantUML має більш формалізовані конструкції для паралельних дій, а BPMN — спеціальні елементи обміну повідомленнями. Mermaid flowchart є зручним для текстового опису та відображення в GitHub, хоча деякі конструкції необхідно позначати явно. Отриману інформацію я використала для самостійного порівняння варіантів. З урахуванням попереднього досвіду роботи з Mermaid, наявності семиденної пробної підписки та зручності інтеграції з GitHub я обрала Activity — Mermaid flowchart.

## Статус

Відповідь ШІ отримано та використано як довідкову інформацію. Остаточне рішення щодо вибору інструмента прийняла самостійно. Відповідність майбутньої діаграми всім вимогам викладача необхідно перевірити за оригінальними умовами завдання 4.
