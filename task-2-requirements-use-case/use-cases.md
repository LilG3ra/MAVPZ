# Use Cases — Онлайн-магазин друкованих книг

## 1. Мета

Описати основні сценарії взаємодії користувачів із системою онлайн-магазину друкованих книг відповідно до ER-моделі Завдання №1.

## 2. Актори

- **Покупець** — переглядає каталог, шукає книги та оформлює замовлення без обов'язкової реєстрації.
- **Працівник магазину** — переглядає та опрацьовує замовлення.

## 3. Основні сценарії використання

**UC-01 — Переглянути каталог книг**

Покупець відкриває каталог, система відображає доступні книги. Якщо каталог порожній, система повідомляє про відсутність книг.

**UC-02 — Знайти книгу**

Покупець вводить назву книги, система виконує пошук і показує результати. Якщо збігів немає, система відображає відповідне повідомлення.

**UC-03 — Переглянути інформацію про книгу та видання**

Покупець обирає книгу, система показує автора, жанр, список видань, ISBN, видавництво, рік публікації, ціну та доступну кількість примірників.

**UC-04 — Оформити замовлення**

Покупець обирає видання та кількість, вводить контактні дані. Система перевіряє дані й залишки, після чого створює замовлення з фіксацією ціни. Якщо примірників недостатньо або дані некоректні, система повідомляє про помилку.

**UC-05 — Опрацювати замовлення**

Працівник магазину відкриває замовлення, перевіряє інформацію та оновлює його статус. Якщо замовлення не знайдено, система повідомляє про це.

## 4. Зв'язки та бізнес-правила

- UC-04 включає перевірку наявності примірників.
- Замовлення повинно містити щонайменше одну позицію.
- Кожна позиція `ORDER_ITEM` пов'язана з конкретним `EDITION`.
- Кількість замовлених примірників не перевищує складський залишок.
- Ціна видання фіксується під час оформлення замовлення.

## 5. Межі роботи

Описуються сценарії використання без реалізації вебзастосунку, бази даних, онлайн-оплати та інтеграції з поштовими службами.
