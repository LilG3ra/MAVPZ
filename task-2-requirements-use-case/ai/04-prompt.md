## Контекст звернення

Завдання №2 є продовженням Завдання №1, присвяченого ER-моделі онлайн-магазину друкованих книг. За основу обрано структуру попереднього завдання, яка містить директорії `adr/`, `ai/`, `diagrams/` та основні документи `README.md`, `spec.md`, `CHECKLIST.md`, `DEFENSE.md`.

Запропоновано розширити структуру відповідно до вимог Завдання №2:

- `requirements/` — функціональні вимоги EARS та нефункціональні вимоги NFR.
- `scenarios/` — сценарії використання у форматі Gherkin.
- `traceability.md` — матриця трасування вимог.
- `use-cases.md` — текстовий опис сценаріїв використання.
- `ASSUMPTIONS.md` — припущення й обмеження проєкту.

## Результат звернення

Запропоновано структуру директорії `task-2-requirements-use-case/`, яка зберігає основні елементи Завдання №1 та доповнює їх файлами для опису вимог, сценаріїв використання й трасування. Нова структура дозволяє розділити специфікацію, діаграми, функціональні та нефункціональні вимоги, Gherkin-сценарії й документацію для захисту.
