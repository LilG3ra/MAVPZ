# ШІ взаємодія 03 — Аналіз Use Cases онлайн-книжкового магазину

## Інструмент

ChatGPT.

## Оригінальний запит користувача

Потрібно оцінити ідею UC (use case). Пропоную створити їх 5 шт. Кейси будуть взаємодіяти щ ER-моделлю (завдання 1). Актори: покупець - працівник. 
По кейсам: переглядання каталогу, знаходження книг, інформація про видання та книгу, оформлення та опрацьовування. Бізнес правил теж взяти з завдання 1.

## Контекст звернення

Для завдання №2 обрано предметну область онлайн-магазину друкованих книг, що є продовженням Завдання №1. У попередньому завданні створено ER-модель із вісьмома сутностями: BOOK, AUTHOR, GENRE, EDITION, PUBLISHER, USER, ORDER, ORDER_ITEM. Запропоновано два актори: покупець і працівник магазину. Планується описати п'ять сценаріїв використання:

- UC-01 — Переглянути каталог книг.
- UC-02 — Знайти книгу.
- UC-03 — Переглянути інформацію про книгу та видання.
- UC-04 — Оформити замовлення.
- UC-05 — Опрацювати замовлення.

## Результат звернення

ШІ проаналізував запропоновані сценарії використання, їхню відповідність предметній області та зв'язок з ER-моделлю Завдання №1. П'ять Use Cases охоплюють основні дії покупця й працівника магазину. Окремо визначено необхідність перевіряти відповідність бізнес-правилам, зокрема оформлення без реєстрації, вибір конкретного видання, перевірку залишків і створення позицій замовлення.

## Статус

Запропоновану структуру Use Cases використано як основу для подальшої підготовки специфікації, текстових сценаріїв та UC-діаграми.
