# ШІ взаємодія 08 — Створення матриці трасування вимог

## Інструмент

ChatGPT.

## Оригінальний запит користувача

Я вже підготувала основні матеріали для другого завдання з КПІ про онлайн магазин друкованих книг. У мене є п'ять Use Cases, сценарії Gherkin для оформлення замовлення, функціональні вимоги EARS та нефункціональні вимоги NFR. Зараз мені потрібно створити матрицю трасування вимог у файлі traceability.md. Я вже розібралася, як робити таблиці в GitHub Markdown, але ще не зовсім розумію, як правильно пов'язати між собою всі вимоги та сценарії. Допоможи скласти таблицю з трьома колонками, де будуть номери функціональних вимог FR, відповідні Use Cases та сценарії Gherkin. У мене є 18 функціональних вимог, тому потрібно врахувати всі від FR-01 до FR-18. Для UC-04 я вже маю чотири Gherkin сценарії. Для інших Use Cases окремих Gherkin сценаріїв немає, тому нічого додатково вигадувати не потрібно. Також перевір, щоб кожна вимога була пов'язана з правильним Use Case і щоб не залишилося пропущених вимог. Нефункціональні вимоги NFR у цю таблицю додавати не потрібно, оскільки вони вже описані окремо. Хочу отримати готову таблицю у Markdown, яку зможу вставити в GitHub, а також коротке пояснення, чому вимоги пов'язані саме так.

## Контекст звернення

Після підготовки функціональних і нефункціональних вимог потрібно було створити матрицю трасування для другого завдання з КПІ. Раніше вже були описані п'ять Use Cases, чотири Gherkin сценарії для UC-04 та 18 функціональних вимог. Також було розглянуто створення таблиць у GitHub Markdown.

## Результат звернення

За допомогою ChatGPT підготовлено структуру матриці трасування з трьома колонками для функціональних вимог, Use Cases та Gherkin сценаріїв. Для вимог FR-01–FR-18 визначено відповідні сценарії використання. Окремо враховано чотири Gherkin сценарії UC-04, а для інших Use Cases додаткові сценарії не створювалися.
