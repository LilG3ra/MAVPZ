## Аналіз результату

ChatGPT допоміг скласти таблицю з трьома колонками для файлу `traceability.md`. У матриці враховано функціональні вимоги від FR-01 до FR-18 та п'ять основних Use Cases. Для UC-04 додано зв'язки з чотирма Gherkin сценаріями, які описують успішне оформлення замовлення та помилки під час оформлення. Для інших Use Cases окремі Gherkin сценарії не додавалися, оскільки вони не були передбачені в завданні. Нефункціональні вимоги залишилися в окремому файлі.

## Оцінка результату

Матриця допомогла краще зрозуміти зв'язки між вимогами та сценаріями використання. Завдяки таблиці стало простіше перевіряти, до якого Use Case належить кожна вимога. Формат Markdown підходить для GitHub і не потребує додаткового оформлення.

## Прийняті рішення

Вирішено залишити три колонки та всі 18 функціональних вимог. Для UC-04 використовувати вже підготовлені Gherkin сценарії, а для інших Use Cases не створювати нових. NFR не включати до матриці, оскільки вони описані окремо.
