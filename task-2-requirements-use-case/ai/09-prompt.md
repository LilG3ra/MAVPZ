# ШІ взаємодія 09 — Підготовка трьох ADR

## Інструмент

ChatGPT.

## Оригінальний запит користувача

Давай створимо три основні ADR для другого завдання з КПІ про онлайн магазин друкованих книг. Перший ADR буде про оформлення замовлення без реєстрації, другий про обов'язкову перевірку наявності книг, а третій про правильні зв'язки між сценаріями Use Case. Запропонуй ідеї, як можна оформити ці рішення, які варіанти варто розглянути та які в них переваги й недоліки. Хочу, щоб ADR були схожі за структурою на документи з першого завдання. Повністю вирішувати за мене не потрібно, я хочу спочатку переглянути твої пропозиції, а потім самостійно вибрати остаточний варіант.

## Контекст звернення

Після створення Use Cases, діаграми, Gherkin, EARS, NFR та матриці трасування потрібно було підготувати ADR. Для цього обрано три основні рішення, які вже пов'язані зі специфікацією онлайн магазину друкованих книг.

## Результат звернення

ChatGPT запропонував оформити три ADR з окремим описом контексту, можливих варіантів, їхніх переваг і недоліків, причин вибору та наслідків. Для кожного ADR було запропоновано по два основні варіанти рішення.

## Статус

Пропозиції щодо оформлення ADR підготовлено для подальшого перегляду та прийняття остаточних рішень.
