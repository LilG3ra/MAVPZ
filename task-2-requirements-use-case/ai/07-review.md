# Огляд 07 — Оформлення таблиці трасування

## Пов'язаний промпт

`ai/07-prompt.md`

## Мета перевірки

Зрозуміти, як правильно створювати та оформлювати таблиці Markdown у GitHub.

## Аналіз результату

ChatGPT пояснив, що таблиця створюється за допомогою вертикальних рисок, а рядок із дефісами відділяє заголовки від даних. Також було розглянуто вирівнювання тексту за допомогою двокрапок.

З'ясовано, що в стандартному GitHub Markdown не можна точно задавати ширину колонок або об'єднувати комірки.

## Оцінка результату

Пояснення допомогли зрозуміти принцип створення таблиць. Для матриці трасування вирішено використати просту таблицю з трьома колонками.

## Прийняті рішення

Залишити стандартне оформлення Markdown без складного форматування, щоб таблиця правильно відображалася в GitHub.

## Статус

Спосіб оформлення таблиці визначено для використання у файлі `traceability.md`.
