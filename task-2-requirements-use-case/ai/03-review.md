# Огляд 03 — Аналіз запропонованих Use Cases

## Пов'язаний промпт

`ai/03-prompt.md`

## Мета перевірки

Оцінити доцільність п'яти запропонованих Use Cases для онлайн-магазину друкованих книг, їхню відповідність акторам системи та узгодженість із ER-моделлю Завдання №1.

## Аналіз результату

Запропоновано п'ять сценаріїв використання: перегляд каталогу, пошук книги, перегляд інформації про книгу та видання, оформлення замовлення й опрацювання замовлення. Перші чотири сценарії описують взаємодію покупця із системою, а п'ятий — дії працівника магазину. Сценарії узгоджуються з основними сутностями ER-моделі. BOOK, AUTHOR і GENRE використовуються для перегляду та пошуку книг, EDITION і PUBLISHER — для отримання інформації про конкретні видання, ORDER та ORDER_ITEM — для оформлення й опрацювання замовлень.

Під час аналізу визначено такі моменти:

1. Під час оформлення замовлення необхідно використовувати конкретне EDITION, а не лише BOOK, оскільки видання мають різні ISBN, ціни та складські залишки.

2. UC-04 повинен враховувати оформлення замовлення без реєстрації, перевірку кількості доступних примірників і створення щонайменше однієї позиції ORDER_ITEM.

3. Покупець оформлює замовлення, а працівник магазину опрацьовує його. Ці дії доцільно представляти окремими Use Cases.

## Оцінка результату

Розподіл сценаріїв між покупцем і працівником магазину відповідає логіці предметної області. Використання ER-моделі Завдання №1 дозволяє зберегти узгодженість між структурою даних і поведінкою системи. Найскладнішим сценарієм визначено UC-04, оскільки він передбачає перевірку даних покупця, доступних примірників, кількості видань і створення замовлення. 

## Статус

Аналіз запропонованих Use Cases підготовлено. Визначено п'ять основних сценаріїв використання та двох акторів системи. Результати аналізу використано для подальшого опису Use Cases, формування UC-діаграми та деталізації UC-04 у форматі Gherkin.
