# ШІ взаємодія 05 — Побудова Use Case-діаграми в Mermaid

## Інструмент

Mermaid AI.

## Оригінальний запит користувача

Створи діаграму Use Case для онлайн магазину друкованих книг через Mermaid Live. Це продовження мого першого завдання, де я створювала ER модель книжкового магазину. На діаграмі потрібно показати двох акторів, покупця та працівника магазину. Покупець повинен мати можливість переглядати каталог книг, знаходити потрібну книгу, переглядати інформацію про книгу та її видання, а також оформлювати замовлення. Працівник магазину повинен мати можливість опрацьовувати замовлення. Також потрібно додати перевірку наявності примірників під час оформлення замовлення. Покажи всі ці дії всередині системи, а акторів розмісти за її межами. Діаграма повинна бути зрозумілою, акуратною та відповідати моїй специфікації.

## Контекст звернення

Після створення специфікації та текстового опису Use Cases для онлайн-магазину друкованих книг виникла необхідність побудувати графічну діаграму сценаріїв використання. Для цього обрано Mermaid AI, оскільки цей інструмент дозволяє створювати діаграми на основі текстового опису.

Основним завданням було відобразити двох акторів, п'ять сценаріїв використання та їхні зв'язки. Діаграма повинна відповідати бізнес-правилам ER-моделі Завдання №1 і специфікації Завдання №2.

## Результат звернення

За допомогою Mermaid AI отримано початкову Use Case-діаграму онлайн-магазину друкованих книг.

На діаграмі відображено двох акторів:

- Покупець.
- Працівник магазину.

Також створено п'ять основних сценаріїв використання:

- UC-01 — Переглянути каталог книг.
- UC-02 — Знайти книгу.
- UC-03 — Переглянути інформацію про книгу та видання.
- UC-04 — Оформити замовлення.
- UC-05 — Опрацювати замовлення.

Додатково створено сценарій "Перевірити наявність примірників". Під час перегляду початкової діаграми виявлено зайві зв'язки між UC-01 та UC-02, UC-02 та UC-03, а також UC-04 та UC-05. Крім того, зв'язок перевірки наявності примірників потребував правильного позначення через `include`. Для усунення цих недоліків підготовлено уточнений запит до Mermaid AI.

## Статус

Початкову Use Case-діаграму створено та проаналізовано. Виявлені недоліки використано для уточнення вимог до наступної версії діаграми. Остаточний результат збережено в директорії `diagrams/`.
