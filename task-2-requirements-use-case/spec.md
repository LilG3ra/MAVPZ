# Специфікація — Вимоги та Use Cases онлайн-книжкового магазину

## 1. Мета

Описати функціональні й нефункціональні вимоги до інформаційної системи онлайн-магазину друкованих книг. Визначити акторів, сценарії використання (Use Cases), вимоги у форматі EARS, нефункціональні вимоги (NFR) та матрицю трасування. Забезпечити узгодженість із ER-моделлю Завдання №1.

## 2. Опис предметної області

Система призначена для онлайн-продажу друкованих книг. Покупці можуть переглядати каталог, шукати книги, отримувати інформацію про авторів, жанри та видання й оформлювати замовлення без обов'язкової реєстрації. Одна книга може мати декілька видань із різними ISBN, видавництвами, цінами й залишками. Замовлення містить одну або декілька позицій, кожна з яких відповідає конкретному виданню.

## 3. Основні сценарії використання

- **UC-01** — Переглянути каталог книг.
- **UC-02** — Знайти книгу.
- **UC-03** — Переглянути інформацію про книгу та видання.
- **UC-04** — Оформити замовлення.
- **UC-05** — Опрацювати замовлення (працівник магазину; потребує підтвердження).

## 4. Зв'язки та бізнес-правила

- Покупець може оформити замовлення без реєстрації.
- Замовлення повинно містити щонайменше одну позицію.
- Кожна позиція замовлення пов'язана з конкретним виданням.
- Кількість замовлених примірників не може перевищувати доступний залишок.
- У момент оформлення фіксується ціна видання.
- Оформлення замовлення обов'язково включає перевірку наявності примірників.
- Для UC-04 описуються успішний та помилкові сценарії Gherkin.

## 5. Критерії прийняття

**Критерій №1:** Створено читабельну Use Case-діаграму з акторами, цілями, межею системи та обґрунтованими зв'язками.

**Критерій №2:** Один складний Use Case описано щонайменше трьома сценаріями Gherkin (`Given / When / Then`), включно з помилковими.

**Критерій №3:** Функціональні вимоги сформульовані у форматі EARS та мають унікальні ідентифікатори.

**Критерій №4:** Описано не менше шести вимірюваних нефункціональних вимог (NFR) з числовими межами.

**Критерій №5:** Створено матрицю трасування між функціональними вимогами, Use Cases та сценаріями Gherkin.

**Критерій №6:** Модель узгоджена з вісьмома сутностями Завдання №1: BOOK, AUTHOR, GENRE, EDITION, PUBLISHER, USER, ORDER, ORDER_ITEM.

**Критерій №7:** Підготовлено README, CHECKLIST, ADR, DEFENSE та задокументовано реальну взаємодію з AI.

Звірка виконання критеріїв — у файлі [CHECKLIST.md](task-2-requirements-use-case/CHEKLIST.md).

## 6. Обмеження (Out of Scope)

У межах завдання не реалізуються вебзастосунок, фізична база даних, повноцінна авторизація, інтеграція онлайн-оплати та поштових служб. Робота обмежується аналізом вимог, моделюванням сценаріїв використання й перевіркою їхньої узгодженості з ER-моделлю.
