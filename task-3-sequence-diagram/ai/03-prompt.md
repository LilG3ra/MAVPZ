# ШІ взаємодія 03 — Створення чотирьох Sequence Diagram

## Інструмент
Mermaid.

## Запит користувача (відтворене формулювання)
Допоможи мені створити 4 Sequence Diagram для онлайн-книжкового магазину за UC-04 із другого завдання. Потрібні сценарії успішного оформлення замовлення, недостатнього залишку книг, неправильної кількості та відсутніх контактних даних. Використай Mermaid, додай учасників, повідомлення між ними, alt, loop та activation bars. Врахуй бізнес-правила з попередніх завдань.

## Контекст звернення
Після створення структури проєкту потрібно було підготувати чотири Sequence Diagram для UC-04 — Оформити замовлення. Основою стали функціональні вимоги та Gherkin-сценарії із Завдання №2, а також ER-модель Завдання №1. Я вирішила створити окрему діаграму для кожного сценарію, щоб було простіше переглядати взаємодію між покупцем, системою та базою даних.

## Результат звернення
ШІ допоміг створити початкові версії чотирьох діаграм:

- SC-01 — успішне оформлення замовлення.
- SC-02 — недостатньо примірників.
- SC-03 — недопустима кількість.
- SC-04 — відсутні обов'язкові контактні дані.

Для діаграм використано Mermaid. Було визначено основних учасників, послідовність повідомлень, перевірки даних та альтернативні результати оформлення замовлення.

## Статус
Початкові версії всіх чотирьох діаграм були створені. Після цього я перейшла до їх перевірки та виправлення.
