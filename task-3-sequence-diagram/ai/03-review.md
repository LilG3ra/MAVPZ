# Огляд 03 — Створення чотирьох Sequence Diagram

## Пов'язаний промпт

`ai/03-prompt.md`

## Мета перевірки

Переглянути початкові діаграми, які допоміг створити ШІ для UC-04, та перевірити, чи охоплюють вони всі чотири Gherkin-сценарії із Завдання №2. Також потрібно було оцінити вибір учасників, послідовність повідомлень і використання можливостей Mermaid.

## Аналіз результату

ШІ запропонував чотири окремі Sequence Diagram: SC-01 для успішного замовлення, SC-02 для недостатнього залишку, SC-03 для недопустимої кількості та SC-04 для відсутніх контактних даних. У діаграмах були показані взаємодії покупця з інтерфейсом, перевірки системи та результати оформлення замовлення. Такий поділ виявився зручним, оскільки кожен сценарій можна перевіряти окремо. Для побудови діаграм використано Mermaid, учасників і повідомлення між ними, а також activation bars і комбіновані фрагменти alt та loop там, де вони потрібні.

Проте початкові діаграми ще не можна було вважати остаточними. Особливо SC-01 потребувала детальнішого опису перевірки залишків і створення замовлення. Також потрібно було звірити назви операцій між сценаріями та перевірити, чи не суперечать діаграми бізнес-правилам із попередніх завдань.

## Оцінка результату

Початковий результат був корисним як основа для подальшої роботи. Я отримала чотири діаграми замість однієї великої, але вирішила не залишати їх без перевірки. Наступним кроком стало уточнення логіки SC-01 та узгодження перевірок у всіх сценаріях.

## Статус

Початкові версії SC-01–SC-04 підготовлено.
