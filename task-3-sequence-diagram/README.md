# Завдання №3 — Взаємодія (Sequence Diagram)

**Дисципліна:** Компоненти програмної інженерії.

**Тема проєкту:** Інформаційна система онлайн-магазину друкованих книг.

## Опис проєкту

Проєкт продовжує Завдання №1 (ER-модель) та Завдання №2 (вимоги, Use Cases і Gherkin) і присвячений моделюванню взаємодій між акторами, інтерфейсом, сервісами та сутностями системи.

Покупець може переглядати каталог, шукати книги, отримувати інформацію про книги та видання й оформлювати замовлення без обов'язкової реєстрації. Працівник магазину переглядає та опрацьовує оформлені замовлення.

## Мета завдання

Треба побудувати UML Sequence Diagram для сценаріїв використання із Завдання №2, описати внутрішню послідовність взаємодій між учасниками системи, повідомлення та відповіді, activation bars і комбіновані фрагменти alt, opt, loop, par.

Перевірити відповідність діаграм сценаріям Gherkin, функціональним вимогам і ER-моделі попередніх завдань.
