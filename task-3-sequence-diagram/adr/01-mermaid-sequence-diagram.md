# ADR-01 — Використання Mermaid для Sequence Diagram

## Статус

Прийнято.

## Контекст

У Завданні №3 потрібно побудувати чотири Sequence Diagram для UC-04 Оформити замовлення із Завдання №2. Діаграми мають показувати учасників, повідомлення між ними, відповіді, activation bars та комбіновані фрагменти `alt` і `loop`. Потрібно було обрати спосіб створення й зберігання діаграм, щоб їх було зручно змінювати та переглядати в GitHub.

## Розглянуті варіанти

### Варіант 1 — Створення діаграм у графічному редакторі

Діаграми малюються в редакторі та додаються до репозиторію як зображення.

**Переваги:**
- Можна самостійно розташовувати елементи на схемі.
- Готове зображення легко переглядати.

**Недоліки:**
- У Git складніше порівнювати зміни між версіями діаграм.
- Зображення дублює вихідний файл діаграми.

### Варіант 2 — Використання Mermaid

Діаграми описуються текстовим кодом Mermaid та відображаються в Markdown на GitHub.

**Переваги:**
- Код можна швидко змінювати й перевіряти через Mermaid Live.
- GitHub відображає діаграми з блоків `mermaid` без окремих PNG-файлів.
- У Git зручно переглядати зміни в коді.
- Mermaid підтримує повідомлення, відповіді, activation bars, `alt` і `loop`.

**Недоліки:**
- Великі діаграми, зокрема SC-01, можуть бути незручними для перегляду без масштабування.
- Код у файлах `.mmd` та Markdown потрібно підтримувати в актуальному стані.

## Прийняте рішення

Для Завдання №3 я обрала Mermaid. Створила окремі діаграми SC-01–SC-04, зберегла їхній вихідний код у файлах `.mmd`. Для перевірки відображення використала Mermaid Live.

## Причини вибору

- Mermaid підходить для всіх чотирьох сценаріїв UC-04.
- Текстовий код зручніше редагувати та зберігати в Git.
- Не потрібно окремо підтримувати PNG-зображення діаграм.
- Діаграми можна переглядати безпосередньо в Markdown на GitHub.

## Наслідки рішення

**Позитивні:**
- Кожен сценарій має окрему діаграму та файл документації.
- Виправлення можна відстежувати через коміти.
- Репозиторій не містить зайвих копій діаграм у форматі зображень.

**Негативні:**
- Потрібно перевіряти коректність Mermaid-коду після змін.
- Треба стежити, щоб код у `.mmd` і `.md` відповідав одній версії діаграми.
- SC-01 залишається великою за розміром.
